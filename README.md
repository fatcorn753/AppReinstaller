# 再インストーラ (AppReinstaller)

指定したアプリを **アンインストール → 選んだ APK をインストール** の順で自動的に連鎖実行する Android アプリ。

## 重要な前提

Android のセキュリティモデル上、**通常のアプリが他のアプリを無言（確認なし）で削除・導入することはできません**。
完全なサイレント実行には次のいずれかが必要です。

| 方式 | 必要なもの |
|---|---|
| このアプリ（本実装） | なし。各手順でシステムの確認ダイアログが出る |
| `adb shell pm uninstall / install` | PC と USB 接続 |
| Device Owner (`dpm set-device-owner`) | 初期化直後の端末に設定 |
| root / system 署名 | root 化端末、または端末メーカーの署名鍵 |

本アプリは1番目の方式です。ボタン1つで「アンインストール確認 → インストール確認」が自動で連続し、
途中の結果をログに表示します。タップは必要ですが、手作業で設定画面を行き来する必要はありません。

## 使い方

1. アプリを起動し、**① APK ファイルを選択**。
   - APK を読み込むとパッケージ名・バージョン・サイズが表示され、②の欄に自動入力されます。
2. **② パッケージ名** を確認（別のアプリを消したい場合はここを書き換えるか、
   「インストール済みアプリから選ぶ」で選択）。
3. **③ 実行** を押す。
   - 初回は「不明なアプリのインストール」の許可を求められるので、設定画面で許可してから再度実行。
   - 対象が未インストールならアンインストールは自動的に省略されます。
4. 完了後、**アプリを起動** ボタンでそのまま起動できます。

## ホーム画面の長押しメニュー (App Shortcuts)

**このアプリのアイコンを長押し**すると、次の項目が出ます。

- 「APK を選ぶ」— 常時表示（静的ショートカット）。押すとファイルピッカーが直接開く。
- 「◯◯ を再導入」— **自分で登録したアプリだけ**が並ぶ（動的ショートカット、最大4件）。
  押すと保存済みの APK でアンインストール→インストールが**即座に走ります**（アプリ画面での操作不要、確認ダイアログのみ）。

### 登録のしかた

1. APK を選ぶ（または対象パッケージを指定する）
2. **「長押しメニューに追加」** を押す → その場でメニューに載る
3. 外すときは同じボタン（「長押しメニューから外す」に変わる）

**「長押しメニューを管理」** を押すと、保存済み APK の一覧がチェックボックスで出て、
どれをメニューに出すかをまとめて選べます。**チェックした順がメニューの並び順**になります。
同じダイアログの「保存済み APK を削除」から、不要になった APK を消せます。

上限は4件です。システム上は15件まで登録できますが、ほとんどのランチャーが4〜5件しか
表示しないため、見えない登録ができないよう丸めてあります。

さらに **「ホーム画面にショートカットを追加」** ボタンで、対象アプリ専用のアイコンをホーム画面に
ピン留めできます（1タップで再インストール開始）。こちらは件数制限なし。

### できないこと

**対象アプリ（例: LINE）のアイコンを長押ししたメニューに項目を追加することはできません。**
他アプリの長押しメニューはランチャーとそのアプリ自身のみが制御でき、第三者アプリが項目を
差し込む API は Android に存在しません。上記のピン留めショートカットが最も近い代替です。

APK はパッケージ名ごとに `filesDir/apks/<パッケージ名>.apk` に保存され、ショートカットから再利用されます。

## アプリの複製

「アプリを複製」から、インストール済みアプリを **パッケージ名を変えて複製** できます。
元のアプリと並べて共存させられます（同じアプリの2アカウント運用など）。

パッケージ名は **3つ目のセグメントだけ**が編集対象です。`com.example.app` なら `app` の部分だけ。
元の値が初期表示されるので、変えたいときだけ書き換えます。
「パッケージ名を変更する」のチェックを外すと、名前はそのままで再署名だけ行います。

### 書き換えている箇所

`package` 属性だけを変えても動きません。以下も併せて書き換えています。

| 対象 | 処理 | 理由 |
|---|---|---|
| `manifest/@package` | 新パッケージ名に変更 | 本体 |
| コンポーネントの `android:name` | **元の**パッケージ名で絶対名に展開 | dex 内のクラス名は元のまま。相対名 `.MainActivity` は新パッケージ基準で解決されてしまい `ClassNotFoundException` になる |
| `provider/@authorities` | 新パッケージ名に置換 | 重複すると `INSTALL_FAILED_CONFLICTING_PROVIDER` |
| 自前定義のパーミッション名 | 新パッケージ名に置換 | 重複すると `INSTALL_FAILED_DUPLICATE_PERMISSION` |
| `taskAffinity` / `process` / `sharedUserId` | 新パッケージ名に置換 | 元アプリとの衝突回避 |

`android.permission.*` など他者の識別子や、`androidx.*` の絶対クラス名は書き換えません。

### 制約

- **署名が変わります。** 端末の `AndroidKeyStore` に初回だけ生成する端末固有の鍵で v2/v3 署名を
  付け直します(固定鍵をアプリに同梱すると、それを知っている全員が同じ署名で APK を作れてしまう
  ため)。自己署名チェックを行うアプリは起動を拒否します。Google ログイン・Firebase・Maps などは
  パッケージ名+署名に紐づくため複製側では機能しません。
- **分割 APK (Play 由来のアプリ) は非対応。** `splitSourceDirs` を持つアプリは理由を出して弾きます。
  自分でビルドした APK や単一 APK のアプリが対象です。
- アプリ名（ラベル）は変わりません。リソース参照のことが多く、`resources.arsc` の書き換えが必要になるため。

### 実装

- [AxmlEditor.kt](app/src/main/java/com/tatu/reinstaller/AxmlEditor.kt) — バイナリ AndroidManifest.xml の読み書き。文字列プールを作り直し、属性が指すインデックスだけ差し替える。
- [ManifestRewriter.kt](app/src/main/java/com/tatu/reinstaller/ManifestRewriter.kt) — 上表の書き換え規則。Android 非依存なので JVM テストで検証している。
- [ApkRepacker.kt](app/src/main/java/com/tatu/reinstaller/ApkRepacker.kt) — ZIP の組み直し。圧縮済みデータをそのままコピーするので再圧縮が起きない。zipalign 相当の整列も行う。
- [ApkCloner.kt](app/src/main/java/com/tatu/reinstaller/ApkCloner.kt) — 全体の流れと apksig による署名。

検証は `./gradlew :app:testDebugUnitTest`。実際にビルドした APK を書き換え・組み直しし、
エントリの中身が保たれていること、整列していること、コンポーネント名が元のままであることを確認します。

## 動作の流れ（内部）

- アンインストール: `Intent.ACTION_UNINSTALL_PACKAGE` + `EXTRA_RETURN_RESULT`
  → 戻り値だけを信用せず、`getPackageInfo()` で実際に消えたか最大3秒ポーリング確認。
- インストール: `PackageInstaller` セッションに APK を書き込み `commit()`。
  `STATUS_PENDING_USER_ACTION` を受け取ったら確認画面を起動し、最終ステータスをログ出力。

## よくある失敗

| ログ表示 | 原因 |
|---|---|
| `CONFLICT (署名違い等)` | 既存アプリと APK の署名が違う。先にアンインストールが必要（本アプリは自動で行う） |
| `ABORTED (キャンセル)` | 確認ダイアログでユーザーがキャンセルした |
| `INVALID (APK が不正)` | APK が壊れている / split APK (.apks, .xapk) は非対応 |
| アンインストールできませんでした | システムアプリ、または端末管理者アプリのため削除不可 |

## ビルド

```
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
./gradlew :app:assembleDebug
```

出力: `app/build/outputs/apk/debug/app-debug.apk`

- AGP 8.13.2 / Gradle 9.4.1 / Kotlin 2.2.21
